# 日語菜鳥村

給日語超級初學者的練習網頁（PWA）。核心是**假名手寫描紅**：清音 92 ＋ 濁音・半濁音 50 ＋ 拗音 66 ＝共 208 字（平／片假名各半），首頁可切換平／片假名。

另外有**數字**（一～十・百，11 字）與**時間與星期**（時分何曜日月火水木金土，11 字）兩個獨立單元——這批內容**不做描紅練習**：台灣學生早就會讀寫這些漢字（漢字對台灣人來說熟門熟路），真正要學的只有它們的日文念法，所以做成「字卡＋讀音＋例字」的形式，看熟了按「我學會了」蓋花丸；也可以到「來玩遊戲」選數字／時間星期，用看字選讀音、看讀音選字的快問快答／翻牌配對來加強記憶。

線上版：<https://jerrihuang.github.io/hiragana/>

## 特色

- **菜鳥養成**：一隻菜鳥小雞當你的分身，隨著學會的字數（花丸，含假名＋數字＋時間星期）從「迷糊蛋」一路變身到「村長」，共 10 段（見 `js/mascot.js`）。
- **假名描紅為主**：照著淡色筆畫，從 ① 開始描。系統會檢查筆順、方向與是否描到位，判定刻意放寬，對初學者友善。
- **數字／時間星期＝讀音卡**：不描紅，只看字卡（字＋羅馬拼音＋注音＋例字），按「我學會了」計入進度。
- **日系文具手帳風**：原稿紙方格、朱色格線、手寫字體，蓋「花丸（はなまる）」印章當獎勵。
- **給台灣初學者**：每個字附注音提示（あ → ㄚ）與一個初級單字／例字。
- **發音**：使用瀏覽器內建語音（需系統有日文語音）。
- **小遊戲**：翻牌配對、快問快答，範圍可選平假名／片假名／數字／時間星期。
- **進度只存在本機**（localStorage），不需帳號、不需連網。

## 如何執行

因為用到 Service Worker 與模組載入，請用本機伺服器開啟（不要直接雙擊 index.html）：

```bash
python -m http.server 8123
```

然後用瀏覽器開啟 <http://localhost:8123>。

（在 Claude Code 中也可用內建預覽：`.claude/launch.json` 已設定好名為 `hiragana` 的伺服器。）

## 數字／時間與星期：為什麼不描紅

一二三四五六七八九十百、時分何曜日月火水木金土這 22 個漢字，台灣學生本來就會讀寫
（漢字對台灣人來說熟門熟路），唯一需要學的是**日文念法**。所以這批內容刻意做成
「字卡＋讀音＋例字」＋「我學會了」按鈕的形式，不套用假名那套描紅練習引擎；
想加強記憶就到「來玩遊戲」選數字／時間星期，用現成的翻牌配對／快問快答練習。

`tools/gen_kanji_strokes.py` 原本是為了幫這批內容抓 KanjiVG 筆順資料而寫的，
抓到的資料（`tools/kanji_strokes.json`）目前沒有被用在畫面上，但腳本與資料都
留著進版控，以後如果真的要做「漢字描紅練習」（例如更進階的 JLPT 漢字）可以直接重用。

## 待辦（下一步方向）

- **月份**：一月～十二月——digit-kanji＋月已經有了，理論上只差把「一月・二月…」組成字卡／單字列出來，工作量不大。
- **日期（ついたち、ふつか、みっか…）**：1～10 號、20 號、30 號等念法是不規則的，
  沒辦法從數字＋日組合推導出來，需要另外整理一份不規則念法對照表，比較花時間，先跳過。
- 發音音檔：見 `audio/發音清單.md`，用 AI 語音工具產生後放進 `audio/kana`、`audio/word`（程式已支援「音檔優先、系統語音備援」）
- 「盲寫」模式（描紅之後不看提示自己寫，僅適用假名）
- 完整離線字體內嵌（目前字體走 Google Fonts，離線時會退回系統字體）
